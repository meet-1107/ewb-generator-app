# Screen 09 — GST return status

## Purpose

Show the user the latest available status for GSTR-1, GSTR-2, and GSTR-3B without implying that the app has filed a return unless a supported integration confirms it.

## Layout

- GSTIN selector and financial year/return period selector.
- Three cards: GSTR-1, GSTR-2, GSTR-3B.
- Each card shows status, period, due date only when sourced, last checked time, and source/provider.
- Status vocabulary is provider-defined and normalized carefully: Filed, Not filed, In progress, Due/Overdue (only when authoritative), or Not available.
- Details view includes source reference and any safe next-step/deep link supported by the provider.

## Behavior and dependency

- Read status from an authorized GST data provider or supported official integration. The EWB API may not provide return statuses; confirm separate access.
- No GST portal scraping and no collection of portal password/OTP by this app.
- If no provider is connected, show “GST status provider not configured,” not an invented status.
- “Refresh status” invokes a rate-limited backend sync and displays sync time/result.
- Avoid presenting GSTR-2 as a filed return if the connected provider reports a different supported return type/status; preserve the provider's exact underlying return identifier.

## Data

- Store snapshots by business, GSTIN, return type, and period, with provider source, provider status, `checkedAt`, and safe reference ID.
- Do not store GST portal credentials or unnecessary tax-return payloads.
- Separate status display from filing/payment actions; this version is status-only unless explicitly expanded.
