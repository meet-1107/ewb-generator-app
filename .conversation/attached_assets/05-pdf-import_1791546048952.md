# Screen 05 — Import invoice PDF

## Purpose

Reduce typing by extracting invoice data from a user-provided PDF, while ensuring a human reviews every value before it can be used for EWB generation.

## Layout and flow

1. Explain supported file types/size and privacy handling.
2. Choose PDF using the native document picker; show file name, size, and remove/replace option.
3. Upload to a private Firebase Storage path with a progress indicator.
4. Show parse state: Uploading → Extracting → Review needed (or Could not read).
5. Display extracted invoice fields in editable form, grouped like the invoice editor.
6. Mark uncertain/missing fields visibly; provide **Save draft** and **Continue to EWB review**.

## Behavior and trust

- PDF parsing runs in a trusted backend service; the mobile client receives structured candidate fields and confidence/uncertainty indicators if the parser supports them.
- Extracted fields are suggestions, not verified facts. Require the user to review and explicitly confirm before generation.
- Keep a source-file reference and parse status. Allow removal of the PDF per retention policy.
- If parsing fails, retain the uploaded file only as permitted by the retention policy and offer manual entry; do not block invoice creation.
- Never send the PDF to an unapproved processor. State where it is processed and how long it is retained.

## Data

- Store file in a private path such as `businesses/{businessId}/invoiceUploads/{uploadId}/source.pdf`.
- Metadata: owner/business, uploader, `storagePath`, content type, size, SHA-256 if computed, uploaded time, parse status, parser version, and linked invoice ID.
- Do not store public download URLs. Issue short-lived authorized access through backend when needed.
- Apply file size/type checks, malware scanning where available, and per-user/business access rules.

## Acceptance checks

- User can correct every extracted value before creating/submitting an invoice.
- Failed extraction leaves a recoverable manual-entry route.
- Another business member cannot read the uploaded source document by changing a client-side ID.
